# 日语罗马音键盘布局 Pro 版（Xime）

一个给 [Xime 输入法](https://github.com/ximeiorg/Xime) 用的全键盘布局 **Pro 版**：
标准 QWERTY 26 个字母键 + 1 个长音键 `-`，顶部追加 0-9 数字行。

键面不放假名助记，保持罗马音键盘本来的样子。相对[普通版](https://github.com/MoruTeaven/xime-layout-romaji)，
把「上滑数字」升级成「上滑常用符号」，并把编辑类操作搬到了键盘上。

> 普通版仓库：<https://github.com/MoruTeaven/xime-layout-romaji>
> 需要 Xime **v3.0.0 及以上**（用到 5 行布局、`swipe_down`、`tab` 动作）。

## 布局

```
第一行   1  2  3  4  5  6  7  8  9  0        点按数字 · 上滑上标 · 下滑下标 · 长按 emoji
第二行   q  w  e  r  t  y  u  i  o  p        上滑符号/功能 · 长按大写
第三行   a  s  d  f  g  h  j  k  l  -        上滑符号/功能 · 长按大写
第四行   ⇧  z  x  c  v  b  n  m  ⌫           上滑符号/功能 · 长按大写
第五行   123  符号  ，(！)  空格(语音)  。(？)  全/半(切语言)  ⏎
```

## 手势

### 数字行（1-0）

| 手势 | 输出 |
| --- | --- |
| 点按 | `1` `2` … `0` |
| 上滑 | 上标 `¹ ² ³ ⁴ ⁵ ⁶ ⁷ ⁸ ⁹ ⁰` |
| 下滑 | 下标 `₁ ₂ ₃ ₄ ₅ ₆ ₇ ₈ ₉ ₀` |
| 长按 | emoji 数字 `1️⃣` … `0️⃣` |

### 字母键

| 手势 | 行为 |
| --- | --- |
| 点按 | 罗马音小写（走 Rime 组合，与手敲该键同一条路由） |
| 长按 | 大写字母，直接上屏 |
| 上滑 | 常用符号，或下方列出的编辑功能 |

上滑的功能键位：

| 键 | 上滑 | 键 | 上滑 |
| --- | --- | --- | --- |
| `q` | Tab | `y` | 恢复（撤销） |
| `a` | 全选 | `z` | 撤销 |
| `x` | 剪切 | `c` | 复制 |
| `v` | 粘贴 | | |

上滑符号一览：

| 键 | 符号 | 键 | 符号 | 键 | 符号 |
| --- | --- | --- | --- | --- | --- |
| `w` | ？ | `s` | 〜 | `b` | ＊ |
| `e` | ！ | `d` | ・ | `n` | ＆ |
| `r` | ： | `f` | ＠ | `m` | … |
| `t` | ； | `g` | ＃ | `-` | ＿ |
| `u` | 「 | `h` | ％ | | |
| `i` | 」 | `j` | ＝ | | |
| `o` | （ | `k` | ＋ | | |
| `p` | ） | `l` | ￥ | | |

### 长音键与最下一排

- 长音键 `-`：点按走 `send_rime`，把 `-` 交给方案处理（例如转成长音符 ー）；上滑下划线 `＿`；长按保留 `- ー ― －` 气泡。
- `，`：点按「、」，上滑「。」，长按「！」。
- `。`：点按「。」，长按「？」。
- 空格：点按空格，长按语音输入。
- `全/半`：点按中英切换（标点随之全角 ↔ 半角），长按切换语言（选择输入法）。
- `123`：点按直接进入数字面板，长按弹出「数字 / 常用符号」二选一。

## 使用前你需要

一个「罗马字 → 假名」的 Rime 方案。Xime 方案商店目前没有日文方案，需要自行导入，
安装后到 Xime → 输入方案 → 已导入 → 右上角启用并部署。

## 安装布局

1. 下载 [xime.custom.yaml](xime.custom.yaml)。
2. Xime → 输入方案 → 已导入 → 右上角 **+** → 浏览器导入。
3. 电脑浏览器打开手机显示的地址（需同一层网络），上传该文件。
4. 回到 Xime 点 **部署**，键盘即应用新布局。

布局文件在设备上的位置是 `rime/xime.custom.yaml`；改动后需要重新部署才生效。
应用内升级会覆盖内置 `xime.yaml`，自定义配置请始终写在 `xime.custom.yaml`。

## 自己改

本文件只写「与内置默认不同的部分」，按键按 keyboard 段的 layout / keys 合并进内置配置。
所以删除任意一段，对应按键就回退到内置默认行为，可以放心拿它当起点。

常用的几张：

- **换上滑符号**：找到对应字母，把 `swipe_up` 换成想要的字符。
- **改上滑的功能**：`swipe_up: { label: "全选", action: "select_all", display: "key", bubble: false }`，
  `action` 可选值见官方文档。
- **长按不改大写**：把该键的 `long_press` 整条删掉，即回退到内置字母气泡。
- **数字行手势**：`swipe_up` / `swipe_down` / `long_press` 三条各管上标、下标、emoji。

完整的字段说明见官方文档：[键盘配置自定义（新版）](https://ime.ximei.me/features/keyboard-config-v2)
