# 日语罗马音键盘布局 Pro 版（Xime）

一个给 [Xime 输入法](https://github.com/ximeiorg/Xime) 用的全键盘布局 **Pro 版**：
标准 QWERTY 26 个字母键 + 1 个长音键 `-`，顶部追加 0-9 数字行。

键面不放假名助记，保持罗马音键盘本来的样子。相对[普通版](https://github.com/MoruTeaven/xime-layout-romaji)，
把常用符号和编辑功能收进了长按，上下滑全部留空。

> 普通版仓库：<https://github.com/MoruTeaven/xime-layout-romaji>
> 需要 Xime **v3.0.0 及以上**（用到 5 行布局、`tab` 动作、`symbol` 面板）。

## 手势约定

只用**点按**和**长按**两种手势，不使用上下滑。

| 区域 | 点按 | 长按 |
| --- | --- | --- |
| 字母键 | 罗马音（进 Rime 组合，与手敲该键同一条路由） | 一个常用符号，或一个编辑功能 |
| 数字键 1-0 | 数字 | 弹出「上标 / 下标」二选一 |
| 长音键 `-` | 走 `send_rime`，交给方案处理（如转成长音符 ー） | 下划线 |
| 大小写 | Shift 键，不占字母键长按 | — |

## 布局

```
第一行   1  2  3  4  5  6  7  8  9  0        点按数字 · 长按上标/下标
第二行   q  w  e  r  t  y  u  i  o  p        点按罗马音 · 长按符号/功能
第三行   a  s  d  f  g  h  j  k  l  -        点按罗马音 · 长按符号/功能
第四行   ⇧  z  x  c  v  b  n  m  ⌫           点按罗马音 · 长按符号/功能
第五行   123  符  ，(！)  空格(语音)  。(？)  全/半(方案)  ⏎
```

## 长按一览

### 功能键位

| 键 | 长按 | 说明 |
| --- | --- | --- |
| `q` | Tab | 发送 KEYCODE_TAB |
| `a` | 全选 | `select_all` |
| `z` | 撤销 | `undo` |
| `x` | 剪切 | `cut` |
| `c` | 复制 | `copy` |
| `v` | 粘贴 | `paste` |

### 符号键位

同一键在全角（中文态）与半角（英文态）下输出不同字形，切换「全/半」时自动跟着变。

| 键 | 全角 | 半角 |
| --- | --- | --- |
| `w` | ～ | `~` |
| `e` | ・ | ・ |
| `r` | ￥ / ＄ | `¥` / `$` |
| `t` | ％ | `%` |
| `y` | ＾ | `^` |
| `u` | ＆ | `&` |
| `i` | ＊ | `*` |
| `o` | （ | `(` |
| `p` | ） | `)` |
| `s` | ＠ | `@` |
| `d` | ： | `:` |
| `f` | ； | `;` |
| `g` | 【 | `[` |
| `h` | 】 | `]` |
| `j` | ＋ | `+` |
| `k` | ＝ | `=` |
| `l` | ＃ | `#` |
| `b` | ／ | `/` |
| `n` | ＼ | `\` |
| `m` | …… | `...` |

`r` 是二选一气泡（￥/＄ 或 ¥/$），因为同一键要放两个货币符号。

### 最下一排

| 键 | 点按 | 长按 |
| --- | --- | --- |
| `123` | 进入数字面板 | 「数字 / 常用符号」二选一 |
| `符` | 进入常用符号面板 | — |
| `，` | ， | ！ |
| 空格 | 空格 | 语音输入 |
| `。` | 。 | ？ |
| `全/半` | 切换中英（全角 ↔ 半角） | 选择输入方案 |

「全/半」键面文字跟随当前状态：中文态显示「全」，英文态显示「半」。

## 全角 / 半角是怎么做到的

不需要在单个按键上做条件判断。Xime 本身就分 `qwerty`（中文态）和 `qwerty_en`（英文态）
两个键盘段，把全角字形写在前者、半角字形写在后者，「全/半」键走 `toggle_ascii`
切换中英态，符号就自动换成对应字形。

省略号按你的要求区分了点数：全角六个点 `……`，半角三个点 `...`。

## 使用前你需要

一个「罗马字 → 假名」的 Rime 方案。Xime 方案商店目前没有日文方案，需要自行导入，
安装后到 Xime → 输入方案 → 已导入 → 右上角启用并部署。

## 安装布局

1. 下载 [xime.custom.yaml](xime.custom.yaml)。
2. Xime → 输入方案 → 已导入 → 右上角 **+** → 浏览器导入。
3. 电脑浏览器打开手机显示的地址（需同一层网络），上传该文件。
4. 回到 Xime 点 **部署**，键盘即应用新布局。

布局文件在设备上的位置是 `rime/xime.custom.yaml`；改动后需要重新部署才生效。
应用内升级会覆盖内置 `xime.yaml`，自定义配置请始终写在 `xime.custom.yaml`。

## 自己改

本文件只写「与内置默认不同的部分」，按键按 keyboard 段的 layout / keys 合并进内置配置。
所以删除任意一段，对应按键就回退到内置默认行为，可以放心拿它当起点。

常用的几张：

- **改长按符号**：找到对应字母，把 `long_press` 换成想要的字符，记得全角/半角两段都改。
- **长按改回大写**：Xime 内置的字母长按是大小写气泡；要恢复就把该键的 `long_press` 整条删掉。
- **改气泡选项**：`long_press: { display: "bubble", values: ["￥", "＄"] }`，
  第一项是左滑、第二项是右滑。
- **单个动作不弹气泡**：`long_press: { label: "撤销", action: "undo", bubble: false }`，
  长按立即执行，适合功能键。
- **注意内置功能键 id**：`symbol` / `emoji` / `voice` 是内置功能键，渲染层对它们有
  特殊绘制（键盘图标、麦克风图标等），会忽略 `label`。想让键面显示自定义文字，
  就用一个自定义 id（本配置的「符」键用的是 `fu`），只在 `tap.action` 里
  引用官方命令 `symbol` 即可。

完整的字段说明见官方文档：[键盘配置自定义（新版）](https://ime.ximei.me/features/keyboard-config-v2)
